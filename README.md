# Smart Expense Tracker — GUI

A desktop expense-management application built with Python, Tkinter, SQLite and REST API integration.

### Features
- Modern desktop GUI
- Add and delete expenses
- SQLite database with SQL CRUD operations
- Dashboard with total spending and transaction count
- Category-wise spending summary
- Currency conversion API can be added as a separate module
- OOP-based architecture

### Run
```bash
python app.py
```

No external package is required for the GUI version.
